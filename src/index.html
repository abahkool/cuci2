CUCI uses ffmpeg for probing, thumbnails and encoding. It prefers your own system install and falls back to a bundled copy when none is found.

Off by default. When enabled, CUCI samples frames with ffmpeg to draw the filmstrip — on long videos this decodes the whole file, so it can take a while.

Auto-detect NSFW scenes

Samples frames from the active clip and classifies each one with an on-device image model, then marks flagged scenes as cuts. Everything runs locally — no frames are uploaded.
